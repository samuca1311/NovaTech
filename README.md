# NovaTech

Link do site: https://samuca1311.github.io/NovaTech/

Projeto em HTML, CSS e JavaScript simples, sem frameworks.

## Organização dos arquivos

- index.html: abre a tela de login.
- home/: página inicial, estilos e interações da loja.
- carrinho/: página, estilos e interações do carrinho.
- produtos/: nove arquivos HTML de produtos, com CSS e JavaScript compartilhados entre eles.
- login/: tela de entrar na conta.
- criar-conta/: tela de cadastro.
- compartilhado/: estilos e script das telas de conta, rodapé e dados do carrinho.
- assets/: fontes, ícones e imagens.
- 404.html: encaminha os endereços antigos para as novas pastas no GitHub Pages.

## Carrinho

Os itens ficam salvos somente no navegador, em localStorage. Nomes, quantidades e preços são usados pela Home e pelas páginas dos produtos.
As imagens salvas usam caminhos a partir de assets/, para que o carrinho continue funcionando entre as pastas.

## Anúncios

A pasta assets/anuncios/ está preparada para as três artes de 1624 × 376. Os espaços dos nove produtos têm uma variação sorteada entre 1, 2 e 3, com três páginas para cada variação. As imagens ainda precisam ser fornecidas.

As funções de login, cadastro e finalização de compra são demonstrativas.
