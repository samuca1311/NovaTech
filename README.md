# NovaTech

Duas telas feitas com HTML, CSS e JavaScript básicos, sem frameworks e sem instalar dependências.

## Como abrir

Abra `index.html` no navegador. **Criar conta** abre `criar-conta.html`; **Entrar** volta à tela de login.

## Arquivos

- `index.html`: login.
- `criar-conta.html`: cadastro.
- `style.css`: estilos e ajustes para telas menores.
- `script.js`: interações simuladas.
- `assets/`: imagens, ícones e fontes locais.

Login, cadastro, recuperação de senha e acesso por Google, Apple ou telefone são demonstrativos. Não há servidor, autenticação real, envio de dados ou armazenamento de senhas. Os exemplos nos campos são placeholders.
